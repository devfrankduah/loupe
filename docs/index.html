Does text hidden on a web page reach an AI agent that reads it?

loupe fetches real web pages, finds the text a person looking at the page can't see, and checks whether that text is still there in the version an AI agent is given to read.

Frank Duah, run on 2 November 2026, 5 pages

The finding

Text hidden with the hidden attribute or display:none mostly still reached the markdown an agent reads: 7 of 8. HTML comments never did: 0 of 14.

Markdown is the cleaned-up text version of a page that many agent tools hand to the model, Bright Data's own scraping tool among them. So the second number is good news, and the first means hiding text with markup does not keep it away from the model. The counts leave out text too short to compare fairly.

How it works

  1. 1

    Fetch the page twice

    loupe asks Bright Data for the raw HTML and, separately, for the markdown version, the same two requests Bright Data's own agent tools make.

  2. 2

    Find what a reader can't see

    It reads the HTML for comments, hidden elements, image and link descriptions, meta tags and noscript blocks, and notes any that sound like orders to an AI.

  3. 3

    Look for it in the markdown

    For each piece of hidden text, it checks whether the same words, in the same order, appear in the markdown an agent would read.

What I'm not sure about

  • Sounding like an order isn't the same as being one

    loupe flags text that contains phrases such as “you are” or “assistant”. That caught 10 pieces of text in this run. Here they are, so you can judge them yourself:

    • en.wikipedia.org, titleGemini (language model)matched language model
    • en.wikipedia.org, titleLarge language modelmatched language model
    • en.wikipedia.org, titleEdit section: System promptmatched system prompt
    • frankduah.me, opacity:006 / 08 Device-Aware RAG Assistantmatched assistant
    • frankduah.me, opacity:006 2026 / Author Device-Aware RAG Assistant Offline-first retrieval that pick...matched assistant
    • frankduah.me, opacity:0Runs the whole question and answer loop on the reader's own device. Nothing i...matched assistant
    • frankduah.me, aria-labelDevice-Aware RAG Assistant linksmatched assistant
    • frankduah.me, aria-labelAI-PR-Assistant linksmatched assistant

  • Some “hidden” text is only waiting to fade in

    48 of the 50 inline-style findings are opacity:0, 48 of them on frankduah.me. That's how scroll-in animations start: the page arrives invisible and JavaScript fades it in, so people do see it. loupe doesn't run JavaScript, so it can't tell the difference.

  • The two versions come from two services

    Bright Data serves the HTML through Web Unlocker and the markdown through its Fetch API. If the two services received slightly different versions of a page, a difference could come from that and not from the markdown conversion.

  • “In the markdown” means the words appear there

    It doesn't prove they got there from the hidden element. A link's description often repeats the link's visible text, so it would match either way.

Words used here

HTML comment
A note in a page's source code, written between <!-- and -->. Browsers skip it, but anything that reads the raw source sees it.
aria-hidden
A marker that tells screen readers to skip an element. It doesn't hide anything from people looking at the screen.
Markdown
A plain-text format with light symbols for headings, links and lists. Agent tools often turn a page into markdown before giving it to a model, because it's shorter than HTML.
Prompt injection
Text written to make an AI model follow instructions its user never gave, for example "ignore your previous instructions". Hiding that text on a web page is one way to deliver it.
