A web page can hide text from you and still hand it to the AI reading it.

loupe fetches real pages, finds the text a person looking at them can't see, and checks whether that text is still there in the version an AI agent is given to read.

How loupe checks a page

  1. It asks Bright Data for the page twice: once as raw HTML, once as the markdown an AI agent is usually given. These are the same two requests Bright Data's own agent tools make.
  2. It reads the HTML for anything a person won't see: comments, hidden elements, image and link descriptions, meta tags and noscript blocks. It also notes text that sounds like an order to an AI.
  3. For each hidden piece, it checks whether the same words, in the same order, are in the markdown.

  • Some “hidden” text is only waiting to fade in

    48 of the 50 findings hidden by inline style are set to zero opacity, 48 of them on frankduah.me. That's how scroll-in animations start: the text arrives invisible and JavaScript fades it in, so people do see it. loupe doesn't run JavaScript, so it can't tell the difference.

  • The two versions come from two services

    Bright Data serves the HTML through Web Unlocker and the markdown through its Fetch API. If they received slightly different copies of a page, a difference could come from that and not from the markdown conversion.

  • “Reached the AI” means the words appear in the markdown

    It doesn't prove they got there from the hidden element. A link's description often repeats the link's visible text, so it would match either way.

Words used here

HTML comment
A note in a page's source code, written between <!-- and -->. Browsers skip it, but anything reading the raw source sees it.
aria-hidden
A marker that tells screen readers to skip an element. It hides nothing from people looking at the screen.
Markdown
A plain-text format with light symbols for headings, links and lists. Agent tools often turn a page into markdown before giving it to a model, because it's much shorter than HTML.
Prompt injection
Text written to make an AI model follow instructions its user never gave, such as “ignore your previous instructions”. Hiding it on a web page is one way to deliver it.
